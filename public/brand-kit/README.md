## Casing

| Kind | Pattern | Example |
| --- | --- | --- |
| Top-level kit folders | `NN_PascalCase` | `03_Logos`, `08_OpenGraph` |
| Nested product folders | PascalCase, spaces allowed | `Brandmark`, `LinkedIn Banners`, `Dark Mode` |
| Format folders | ALL CAPS | `SVG`, `PNG` |
| Color names | Title Case | `Black`, `White` |
| Logo files | `liferow_` + snake_case | `liferow_brandmark_black.svg` |
| Pictograms | kebab-case, same stem in SVG and PNG | `grad-cap.svg` |
| Social avatars | `liferow_avatar_` + snake_case | `liferow_avatar_black_white.png` |
| Social banners | `Color_Network_Banner_N.png` | `Black_Linkedin_Banner_1.png` |
| Open Graph | `OG image - Color.png` | `OG image - Black.png` |
| Palette | `Life Row Color Palette - YYYY.ase` | `Life Row Color Palette - 2026.ase` |
| Decks / guidelines | `Life Row - Title.ext` | `Life Row - Brand Guidelines.pdf` |

Do not use all caps in public copy or logo wordmarks. Group names are Title Case. Section labels stay sentence case unless they are short proper titles (`Mission`, `Field days`).
